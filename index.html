設定

このリポジトリ情報とGitHubトークンを入力してください。入力内容はこのブラウザにのみ保存されます。

トークンは Settings → Developer settings → Fine-grained tokens で発行し、対象リポジトリのみ / Contents: Read and write の権限にしてください。
📖 トークンが切れた時の再取得手順（90日間）
Fine-grained tokenは期限が切れるとコミット・アプリ登録ができなくなります。以下の手順で90日間の新しいトークンを発行してください。
  1. 下のボタンからGitHubのトークン設定を開き、「Generate new token」を押す
  2. Token name: workbench-token などと入力
  3. Expiration: 90 days を選択（90日）
  4. Repository access: Only select repositories → workbench を選択
  5. Permissions: Repository permissions 内の 「Contents」 を Read and write に設定
  6. 最下部の 「Generate token」 を押し、発行された github_pat_... を上の欄に貼り付けて「保存する」
🔗 GitHub トークン発行ページを開く (Fine-grained) →
以下は「トピックを付けたリポジトリを自動で一覧に表示する」ための設定です(任意)。両方のGitHubアカウントのユーザー名を入れてください。
