# WORKBENCH アップデートキット (トークンカウントダウン & アカウント追加対応版)

「トークンの90日有効期限カウントダウン」「切れた時の再取得ガイド」「新しいGitHubアカウントの追加機能」を追加した更新ファイルです。

---

## 📦 ファイル構成

- **`index.html`（★今回変更されたメインファイル）**
  - **トークン有効期限のカウントダウン**:
    - 設定画面で「+90日（標準）」ボタンを押すだけで期限を設定でき、「残り89日」などリアルタイムに日数をカウントダウン表示。
    - 期限が近付くと黄色（14日以内）、期限が切れると赤色の警告バッジが表示され、期限切れで悩むことがなくなります。
    - ヘッダー右側にも「🔑 PAT 残りXX日」のバッジが表示され、一目で状態が分かります。
  - **トークン再取得手順ガイド（直接リンク付き）**:
    - 設定画面内に [GitHub トークン発行ページを開く](https://github.com/settings/tokens?type=beta) の直リンクと、選ぶべき設定（90 days / Only select repositories: workbench / Contents: Read and write）をチェックリスト形式で常時掲載。
  - **新しいGitHubアカウントの追加機能**:
    - `chinta44` と `torao44` 以外のアカウントも、設定画面の「登録済みGitHubアカウント一覧」やアプリ編集画面の「+ 新規追加」から自由に追加できます。追加したアカウントはフィルターにも自動反映されます。
- **`apps.json`**
  - 既存の26アプリに開発系譜（devInfo）が追加されたカタログデータです。
  - **※既にGitHub側の apps.json を手動で編集・更新済みの場合は、この apps.json はアップロードせず、`index.html` だけをアップロードしてください。**

---

## 🚀 GitHubへのアップロード手順（変更ファイルのみ）

今回アップロードするのは基本的に **`index.html` だけ** で大丈夫です！

1. このZipファイルを解凍します。
2. ブラウザで [https://github.com/chinta44/workbench](https://github.com/chinta44/workbench) を開きます。
3. 右上の **「Add file」** → **「Upload files」** をクリックします。
4. 解凍した **`index.html`** をドラッグ＆ドロップします。
5. 画面下の緑色の **「Commit changes」** を押します。

約1〜2分後、[https://chinta44.github.io/workbench/](https://chinta44.github.io/workbench/) をリロードすると、最新機能（トークンカウントダウン、アカウント追加機能）が使えるようになります。

---

## 🔑 新しい90日トークンの設定方法

1. `chinta44.github.io/workbench/` を開き、右上の **「⚙（設定）」** を開きます。
2. 今回発行した新しいトークン（`github_pat_...`）を貼り付けます。
3. 有効期限欄の **「+90日(標準)」** ボタンを押すと、今日から90日後の日付が自動入力されます。
4. **「保存する」** を押せば、ヘッダーに「🔑 PAT 残り90日」と表示され、カウントダウンが始まります！
